# 财务数据与估值口径复核

复核日期为 2026-11-20，标的为贵州茅台（600519.SH）。本地原始三表覆盖 2014 年报至 2026 年三季报，网站展示 2014–2025 年年度合并报表。本文记录对本地数据、计算链和公开报告的核对范围。

## 论文与项目公式

| 论文页码 | 项目口径 |
| --- | --- |
| 第 8–10 页 | 合并权益＝净经营资产－净金融负债。归母权益再扣少数股东权益。经营端与融资端自由现金流勾稽依赖统一的综合收益与净分配口径。 |
| 第 12–14 页 | 重构自由现金流采用税后经营收益减净经营资产增加额。简式自由现金流采用报表经营活动现金流量净额减现金资本开支。分别保留结果与差额。 |
| 第 14–15 页 | 剩余权益收益＝归母综合收益－权益必要报酬率×期初归母权益。归母净资产收益率继续采用归母净利润。 |
| 第 15–16 页 | 历史 AEG 采用归母综合收益与反推的上年归母净分配。权益剩余收益和前瞻 AEG 估值使用同组假设，并比较两者结果。 |

论文页码沿用原文页脚。25% 税率分摊、经营与融资分类、永续增长率、必要报酬率和净金融负债与少数权益的账面价值均按项目口径列示。[Penman 论文原文](../app/public/knowledge/Penman_What_Matters_in_Company_Valuation.pdf)
