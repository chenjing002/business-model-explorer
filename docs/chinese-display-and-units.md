# 中文展示与金额单位

已完成（2026-11-19）。网站默认采用简体中文，专业术语保留必要的英文缩写、公式符号或括号对照。

## 展示规则

- 导航、各分析页、图例、提示、说明、数据异常提示及知识库正文采用中文。
- 219个报表科目名称来自 `config/mapping_tushare.yml` 的 `label_zh`，前端目录为 `app/src/locale/accounts.json`。
- 原始科目标识和来源信息保留。地图明细显示中文科目，鼠标提示可查看原始英文标识。
- 重构分析指标明确标注口径：税后经营收益（OI）不等同于利润表“营业利润”；营业总收入与营业收入、归母权益与含少数股东的合并权益分别说明。
- 知识库现有34个中文条目，新增“金额、股数与中文单位”，同时支持中文和英文检索。
- 后续开发约定已写入根目录 `AGENTS.md`。

## 单位规则

| 数据 | 输入与储存单位 | 页面展示 |
| --- | --- | --- |
| 财务金额、模型价值、总市值 | 人民币元，`CNY_yuan` | 亿元，原值除以100,000,000 |
| 股价、模型每股价值 | 元/股 | 元/股，保留两位小数 |
| 金额勾稽差额 | 元 | 元；不足 1 分时优先显示十进制小数，并注明绝对值不足 1 分；极端微小值才使用科学计数法 |
| 收益率 | 小数 | 乘100后显示百分比 |
| 收益率之差 | 小数 | 乘100后显示百分点 |
| 周转天数 | 天 | 天，不缩放 |
| 周转倍数、市盈率等 | 倍数 | 倍，不做金额缩放 |

例如1,000,000,000元为10.00亿元，不能将原先英文的“1B”直接替换成“1亿”。

Tushare每日指标原始总市值为万元、总股本为万股，`pipeline/market.py` 已各乘10,000转为元和股。前端不得重复换算；加载时检查金额单位，不接受非 `CNY_yuan` 输入。

金额格式集中在 `app/src/format.ts`。`toYiYuan` 接收元；`formatAmount` 接收元并附单位；`formatYiValue` 专门接收已经按亿元缩放的图表数值，避免二次缩放。科目及展示文字在 `locale.ts` 复制转换，原始JSON、数据库、金额、比率、日期和标识不改动。
