# 模块 14：参考案例

参考案例现只保留 [贵州茅台 600519：六步读商业实质](/cases/moutai-600519)。
`/cases` 默认展示该案例；原 Amazon 与运输设备案例已移除，旧地址显示“未找到该参考案例”。
案例使用 `app/public/data/600519.SH.json` 公司数据包，无需单独的案例数据包。
页面金额按亿元展示，数据包金额原值为人民币元（`unit: CNY_yuan`）。

## 六步导览

1. **总览**：区分净经营资产收益率（RNOA）与合并净资产收益率（ROTCE），观察经营资本和净金融资产。
2. **商业经济地图**：追踪资金来源、资产投向、分红和资本开支。
3. **盈利驱动树**：按年度拆解 RNOA = 税后经营利润率（OPM）× 净经营资产周转率（ATO）。
4. **资本与再投资**：查看净经营资产变化、再投资率、存货及营运资本周转。
5. **价值创造**：查看资本费用、剩余经营收益（ReOI）和增长效应。
6. **估值与反向分析**：比较市场价值、模型价值和隐含增长假设。

每一步都链接到相应分析页面，链接年度锚定公司数据包的最新年度。案例小结说明
OI 为重构口径，不直接等同于报表“营业利润”；比率采用平均资本，必要报酬率
与增长率为显式假设，空值保留原因。页面可以下载公司数据包 JSON 复核。

## 实现与验证

- `app/src/MoutaiCase.tsx`：六步导览、中文口径和深链接。
- `app/src/moutaiFacts.ts`：读取数据包中已算好的结果，选择展示年份；不做财务计算。
- `app/src/ReferenceCasesView.tsx`：案例入口、未知地址提示和公司数据状态。
- `app/tests/reference-cases.test.mjs`：验证唯一案例、旧地址、六步内容、单位和加载状态。

运行 `cd app && npm test && npm run build` 验证前端。公司数据包由现有 Python
管线生成，前端只做取值与展示。
